Bài 1 — Quản lý giỏ hàng bằng Function và Object

Bài tập chạy hoàn toàn trên console.

Cần hoàn thiện trong cart.js

  • get totalQuantity - tổng số lượng sản phẩm
  • get subtotal - tổng tiền hàng (price × quantity)
  • set applyCoupon - gán _discountRate nếu mã hợp lệ, sai thì báo lỗi
  • get totalPrice - subtotal sau khi trừ giảm giá
  • addItems(...newItems) - trùng id thì cộng dồn, chưa có thì quantity mặc định 1
  • updateQuantity(id, newQuantity) - update số lượng sản phẩm theo id
  • removeItem(id) - xoá sản phẩm theo id
  • getItemsByCategory(category) - lọc sản phẩm theo danh mục
  • printInvoice() - in hoá đơn chi tiết ra console
